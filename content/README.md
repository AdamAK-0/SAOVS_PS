# Content Root

Put the server-side content files here as `content/files`, or set
`SAOVS_CONTENT_ROOT` to another directory.

For Adam's local lab, the working content root is:

```text
C:\Users\Adam\SAOVS_Project\SAOVS\data1\com.bandainamcoent.saovsww\files
```

The server can serve direct files such as `sword.db` and Unity cache bundle
payloads from `UnityCache/Shared/<url-cache-hash>/<bundle-hash>/__data`.
